# POV LED Fan Display

## Overview
A DIY Persistence of Vision (POV) LED fan that creates the illusion of floating images, text, and animations using rapidly rotating RGB LEDs.

## Features
- Custom LED animations and patterns
- Programmable RGB lighting
- Microcontroller-controlled display
- Compact design
- Custom PCB

## How It Works
A motor spins an LED display arm while a microcontroller changes the LED colors at precise times, creating the illusion of a floating image.

## Project Goals
- Design a custom PCB
- Create colorful LED animations
- Keep costs affordable
- Build a safely enclosed display
